# Thaya Netrik (தாய நேத்ரிக்)
> **Ancient Tamil Traditional Thayakattai Strategy Game — Digital Multiplayer Experience**
>
> **Brand**: Netrik.AI | **Platform**: Flutter (Android, iOS, Web, Tablet, Desktop)

---

## 🌟 Overview
**Thaya Netrik** brings the traditional Indian board and dice game of **Thayakattai** (தாயக்கட்டை) into the digital age. Built with Flutter and Clean Architecture, it delivers authentic rules, rich Indian aesthetics, intelligent AI opponents, and cross-platform multiplayer.

---

## 🎲 Key Features
- **Authentic Thayakattai Dice Mechanics**: Dual long cuboidal dice with 1 (Thayam), 2, 3, 4, 5, 6, and 12 (Panirendu) outcomes.
- **Bonus Turns & Combos**: Extra rolls granted on 1, 5, 6, 12, and opponent captures ("Vettu").
- **Authentic Traditional Rules**:
  - Piece entry requires rolling **Thayam (1)**.
  - Safe squares (**Malai / Kallu**) marked with sacred cross motifs.
  - Mandatory capture qualification before tokens can advance along the homeward path to **Pazham**!
- **Supported Player Counts**: Fully implemented 2-player, 4-player, 6-player, and 8-player board geometries and turn order.
- **Multiple Game Modes**:
  1. **Local Pass-and-Play**: Shared device gameplay with turn alerts and timer.
  2. **Play Against AI**: Easy, Medium, and Hard heuristic AI opponents.
  3. **Private Online Multiplayer**: Create & join rooms using 6-character room codes.
  4. **Public Online Multiplayer**: Matchmaking by player count.
  5. **Friends Match**: In-app friend list and invitations.
- **Bilingual Localization**: Native support for **Tamil (தமிழ்)** and **English**.
- **Responsive Layout**: Designed for small phones, tablets, and wide desktop screens.
